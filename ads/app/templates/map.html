Map setup

Where do I get the keys?

In Google Cloud, project mcdp-ads: APIs & Services → Library, enable Places API (New) and Maps JavaScript API. Google Maps needs a billing account linked to the project, even though this stays within the monthly free allowance.

Credentials → Create credentials → API key, twice:

Browser key: Application restrictions → Websites → https://ads.mcdp.com/*. API restrictions → Maps JavaScript API and Places API (New).

Server key: API restrictions → Places API (New) only.

Optional: Google Maps Platform → Map management → Create Map ID (JavaScript, Vector) and paste it here. Without one, Google's demo map style is used.

Set a budget alert (Billing → Budgets & alerts, e.g. $5) so you'd hear about any charge.
