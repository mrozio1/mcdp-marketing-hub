Email sending

Studio email campaigns go out through Azure Communication Services, one sending address per practice on its own domain. A practice can send once SPF, DKIM and DMARC are found and a test has gone through.

1 · Connect Azure Communication Services {% if configured %}Connected{% endif %}

  1. In the Azure portal: create a Communication Services resource and an Email Communication Services resource.
  2. In the Email resource, Provision domains › Add domain › Custom domain for each practice (e.g. havensorthodontics.com). Azure shows a TXT and two CNAME records; add them in Cloudflare, then Verify in Azure.
  3. Under the domain, MailFrom addresses: add the sending address (e.g. news@…) and its display name, e.g. "Havens Orthodontics". That name is what people see as the sender.
  4. Connect the domains to the Communication Services resource (Email › Domains › Connect domain), then copy its Keys › Connection string here.

Azure starts custom domains at 30 a minute and 100 an hour for the whole account. Ask Azure support for more (it wants a bounce rate under 2%), then raise these to match. Big lists send over several hours on their own.

Bounces (optional, recommended)

In the Communication Services resource: Events › + Event Subscription, event type Email Delivery Report Received, endpoint type Web Hook, this URL:

{{ events_url }}

Bounced addresses are then taken off that practice's lists automatically.
