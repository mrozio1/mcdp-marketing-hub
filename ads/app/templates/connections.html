Where do I get this?

In Meta Business Settings → Users → System users: add a system user and use Assign assets to give it the practices’ ad accounts with Manage campaigns (View performance is enough for reports only). Also assign the practices’ Facebook Pages (with Create ads and View Page performance) and their Instagram accounts, for new ads and organic post stats.

Then Accounts → Apps → MCDP Social → Assign people: add the system user with full control. Without this, Generate token says “No permissions available”.

Finally Generate token for MCDP Social with no expiry and only these permissions: ads_read, ads_management, business_management, pages_show_list, pages_read_engagement, read_insights, instagram_basic, instagram_manage_insights. Ticking extra ones (WhatsApp, Threads, commerce…) can make Meta block the app. If ads_read isn’t offered, add the “Measure ad performance data with Marketing API” use case to the app in developers.facebook.com.

What goes into Salesforce

Each visit becomes a completed Task on the office’s Account: the subject is “Field visit: office name”, assigned to the agent if they have a Salesforce user with the same email (otherwise to the connected user), with who they met, the relationship, what was dropped off and the cost, and the notes. The first person met is the Task’s contact.

Everyone met becomes a Contact on that Account, matched by email first so nobody is duplicated. Offices already in Salesforce are matched by name (and ZIP); new ones are created with Type Referral office. A follow-up date becomes an open Task on that day. Existing Accounts and Contacts are never edited.

Where do I get this?

In Salesforce: Setup → External Client App Manager → New External Client App. Name it “MCDP Hub”, tick Enable OAuth, set the callback URL to {{ sf_redirect }}, and add the scopes Access the identity URL service, Manage user data via APIs (api) and Perform requests at any time (refresh_token, offline_access). Tick Require secret for Web Server Flow and Require secret for Refresh Token Flow. Save, then open Settings → OAuth Settings → Consumer Key and Secret.

Sign in with a Salesforce user that can create Accounts, Contacts and Tasks. Add a Referral office value to the Account Type picklist so it shows in list views and reports.
